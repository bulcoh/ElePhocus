===============================
   ElePhocus 설치 방법
===============================

1. ElePhocus 아이콘을 Applications 폴더로 드래그하세요
2. 처음 실행 시:
   - 우클릭 → "열기" 클릭
   - 경고창에서 "열기" 버튼 다시 클릭
3. 이후로는 일반 더블클릭으로 실행 가능!

+MacOs에서 Elephocus를 확인되지 않은 개발자가 배포한 앱으로 규정하기 떄문에 그렇습니다.
++처음에 실행에 실패했다면, 설정-개인정보 보호 및 보안 - 보안 섹션 - 확인되지 않은 앱 경고 메세지 옆에 있는 '열기' 버튼을 클릭합니다.
